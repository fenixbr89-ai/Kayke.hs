# Portfólio de vídeos em motion

Site estático em HTML, CSS e JavaScript. Não precisa de build.

Para adicionar um vídeo:
1. Coloque em `assets/videos/` o arquivo .mp4 (vertical 9:16) e uma capa .jpg com o mesmo nome
2. Coloque em `assets/videos/previews/` um trecho de uns 6 segundos, sem som e em 360px de largura, com o mesmo nome
3. Adicione uma linha na lista `VIDEOS` em `assets/js/videos.js`

A aba de um segmento aparece sozinha quando ele ganha o primeiro vídeo.

Publicação: Settings, Pages, branch `main`, pasta raiz.
